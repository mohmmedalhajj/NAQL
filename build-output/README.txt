NAQL | نقل - تطبيق أندرويد احترافي لنقل ومشاركة الملفات دون إنترنت

حول التطبيق:
NAQL هو تطبيق أندرويد أصلي (Native Kotlin & Jetpack Compose) تم تصميمه لنقل الصور،
الفيديوهات، التطبيقات (APKs)، المستندات، وكافة أنواع الملفات بين الهواتف القريبة مباشرة
نقطة-إلى-نقطة (P2P) دون الحاجة إطلاقاً إلى اتصال بالإنترنت أو خوادم سحابية أو تسجيل دخول.

المحتويات في مجلد build-output:
----------------------------------------
1. APK/
   - NAQL-debug.apk: ملف التثبيت النهائي المحدّث (22.7 ميجابايت)، جاهز للتثبيت على الهواتف.
   - البصمة الرقمية (SHA-256):
     4819b3f059015058110e5a8683c022c01084791c2596825fc3c2377ed7c4aa4e

2. reports/
   - build-report.txt: تقرير مفصل حول عملية بناء المشروع ونسخ Gradle والتحسينات المنجزة.
   - test-report.txt: نتائج اختبارات الوحدات وRobolectric لاختبار سلامة البروتوكول والبيانات (9/9 بنجاح 100%).
   - device-test-report.txt: تقرير بيئة التشغيل والتحقق ودليل الاختبار الميداني على هاتفين فعليين.

3. README.txt:
   - هذا الملف الإرشادي المحدّث.

تعليمات التثبيت:
----------------------------------------
1. تثبيت التطبيق عبر مدير الملفات على الهاتف:
   - انسخ ملف NAQL-debug.apk إلى ذاكرة الهاتف.
   - اضغط على الملف لتثبيته، ووافق على خيار "تثبيت التطبيقات من مصادر غير معروفة" إذا طُلب ذلك.
2. التثبيت عبر سطر الأوامر (ADB) للمطورين:
   adb install -r build-output/APK/NAQL-debug.apk

التقنيات المستخدمة:
- Google Nearby Connections API (Strategy.P2P_STAR / POINT_TO_POINT)
- Kotlin Coroutines & StateFlow
- Jetpack Compose Material 3 مع دعم كامل للغة العربية (RTL) وتخطيط مرن للشريط العلوي
- Coil VideoFrameDecoder و MediaMetadataRetriever لمعاينة الفيديوهات بفعالية
- Android Room Database لحفظ السجلات والملفات المستلمة
- FileProvider ومسار Downloads/NAQL لحفظ ومشاركة الملفات بأمان بنظام أندرويد
